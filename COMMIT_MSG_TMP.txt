召唤物自身技能层：只建模"无条件改变普攻"的两类，实测仅 3 条需改量

背景：§17 的召唤物数值当时标注为"仅普攻下限"。本次把召唤物**自身的技能**纳入，
但结论与预期相反 —— 缺口不在"持续输出"，而在"一次性入场伤害"。

数据（tools/build-summons.mjs → data/summons.json 的 ownSkill）
- 逐条分类召唤物技能，只建模两类"无条件且确实改变普攻"的改量：
  攻击力倍率（`atk` 加成 / `atk_scale` 提升至）、攻击间隔（`attack_speed` 百分比 / `base_attack_time` 秒差）
- 42 条伤害型召唤物里**只有 3 条**需要改量，其余 39 条的持续数值本来就是对的
- 明确排除（不计入持续 DPS）：一次性入场/触发伤害 18 条、技能名为效果伤害 7 条、
  无描述可判定 4 条、周期伤害（每秒）2 条、概率触发 1 条

三条实测变化
- 鸿雪「打字机」541.3 → 3450.5（S3「锐笔速写」攻击力提升至 255% 且 base_attack_time −0.6s）
- 傀影「镜中虚影」589.2 → 707.1（S2「血色乐章」10 层 ×20%，每击消耗一层 → 全程平均 ×1.2）
- 衡沙「发条羽兽」212.5 → 340.0（S1「上紧发条」attack_speed=60 → 间隔 ÷1.6）

结构/判据教训（都踩过）
- 把召唤物技能的 atk_scale 当普攻倍率 → 第一版判据"有倍率键即建模"一次命中 19 条，
  其中 16 条是错的（梅尔「爆破回收」6 倍是引爆回收的一次性伤害）
- 叠层判定必须最先跑：傀影「血色乐章」描述含"部署后立即"，会被一次性入场规则误杀
- attack_speed 是百分比不是秒（+60 → 间隔 ÷1.6）
- "2." 前缀键是"第二形态"（弦惊高级形态），套到基础形态会算成"攻击力 −20%"，
  而描述写的是"大幅度强化" → 必须跳过并标注未建模
- 不能用召唤物技能序号反推干员技能序号：令三形态共用 sktok_ling_soul3

验证
- tools/verify-summons.mjs 33 → 40 断言（新增自身技能倍率、一次性伤害不计、第二形态不套用）
- 全量回归：引擎 76 / DB 16 / API 30 / LLM 18 / 冒烟 1362 次意外异常 0
- 锚点零漂移：银灰 5524.6 / 望 179056 / 凯尔希 701.0 / 令 548.7 全部不变
