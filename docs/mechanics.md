# 机制层文档（draft）

> 本文件记录评测引擎依赖的明日方舟核心机制与公式。
> 状态：**公式为公开机制知识的实现草案**，待游戏数据（`gamedata_const.json` 等）拉取后用真实常量校准。

## 1. 伤害公式

| 类型 | 公式 | 说明 |
|---|---|---|
| 物理 | `max(⌊ATK×倍率 − DEF⌋, ⌊ATK×倍率×0.05⌋)` | 防御为线性减伤；5% 保底 |
| 法术 | `max(⌊ATK×倍率×(1 − RES/100)⌋, ⌊ATK×倍率×0.05⌋)` | 法抗为百分比减伤；5% 保底 |
| 真实 | `⌊ATK×倍率⌋` | 无视 DEF 与 RES |

- 全部向下取整（与游戏内数值一致）
- 段数/目标数：合计伤害 = 单段伤害 × 段数 × 目标数

## 2. 攻速与攻击间隔

```
攻击间隔 = 基础间隔 / (1 + 攻速加成/100)
```

- 例：基础 1.5s，攻速 +50 → 1.0s
- 技能期攻速加成仅作用于技能期；技能外平 A 用基础攻速

## 3. SP 与技能覆盖率

```
技能周期 = 充能时间 + 持续时间
覆盖率   = 持续时间 / 技能周期
```

- 自动回复：1 SP/s（`chargeTime = spCost − spStart` 秒）
- 攻击回复：每次攻击回 1 SP（`chargeTime = (spCost − spStart) × 攻击间隔`）
- 受击回复 / 其他：暂按 1 SP/s 简化 ⚠️ 待校准

## 4. 输出指标

| 指标 | 定义 |
|---|---|
| 技能期 DPS | 技能开启期间每秒伤害（含技能倍率/攻速/段数） |
| 平 A DPS | 技能外每秒伤害 |
| 平均 DPS | `技能期 DPS × 覆盖率 + 平A DPS × (1−覆盖率)` |
| 费用效率 | `平均 DPS / DP 费用`（粗略性价比） |
| 输出画像 | DEF×RES 网格上的平均 DPS 表（物理看 DEF 行，法术看 RES 列） |
